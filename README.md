# SolarGuide Nigeria — MVP

Mobile-first static MVP for a Nigeria-first solar sizing product.

## Included
- Appliance-based load calculator
- Daily energy, peak load and inverter sizing
- Battery sizing for flooded lead-acid, tubular, AGM, GEL and LiFePO4
- Panel count and PV sizing
- Panel technology recommendations: N-type TOPCon, bifacial TOPCon, mono PERC, polycrystalline and thin-film
- Location presets
- Roof-area check
- Shareable result text
- SEO metadata
